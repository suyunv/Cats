# 🐾 루비 & 끝순이의 우당탕탕 놀이터

집사님의 사랑스러운 두 반려묘, 듬직하고 다정한 **루비**와 작고 뚱냥매력 넘치는 **끝순이**를 위한 귀엽고 활동적인 분위기의 프리미엄 웹 애플리케이션입니다!

## 🚀 시작하는 방법

이 프로젝트는 순수 HTML, CSS, JavaScript로 제작되어 **별도의 빌드나 설치 과정이 필요하지 않습니다.**

1. 본 폴더(`Cats`)의 `index.html` 파일을 **마우스로 더블 클릭**하거나 브라우저(Chrome, Edge, Safari 등)로 드래그 앤 드롭합니다.
2. 혹은 프로젝트 폴더 내에서 다음 명령어를 통해 로컬 웹 서버를 실행하여 접속할 수 있습니다:
   * Python 사용 시: `python -m http.server 8000` 후 브라우저에서 `http://localhost:8000` 접속
   * Node.js / npx 사용 시: `npx serve` 후 표시되는 주소로 접속

## ✨ 제공되는 핵심 기능

1. **🎨 액티브 & 큐트 디자인 시스템**:
   * 활동적이고 생기 넘치는 코랄 오렌지, 치즈 옐로우, 상큼한 민트 그린 색상 테마.
   * 부드러운 글래스모피즘 보드와 동화 속 손글씨 느낌의 'Jua' & 'Nunito' 구글 폰트 적용.
   * 뒷배경에 둥실둥실 떠다니는 파스텔 버블 장식 요소.

2. **🐾 젤리 발자국 커서 트레일**:
   * 마우스를 움직일 때마다 화면에 알록달록 귀여운 고양이 젤리 발자국(`🐾`)이 은은하게 생겨났다가 위로 둥둥 뜨며 페이드아웃되는 감성적인 커서 트레일 효과.

3. **🏋️‍♂️ 루비의 광속 장난감 사냥 (Play Zone 1)**:
   * 마우스를 움직여 털실/장난감을 이리저리 이동시키면 루비의 우람하고 강인한 발바닥(발가락 아이콘)이 스프링 탄성 물리엔진처럼 쫓아옵니다.
   * 마우스 속도에 따라 실시간으로 루비의 "사냥 속도(km/h)"가 계산되며, 사냥 성공 시 귀여운 별 가루(⭐) 이펙트가 발생합니다.

4. **💅 뚱냥이 끝순이 쓰다듬기 (Play Zone 2)**:
   * 끝순이의 뚱하고 러블리한 표정이 있는 프로필의 **이마, 볼살, 턱밑** 핫스팟 영역을 쓰다듬어 보세요.
   * 클릭 시 핑크 하트와 음표 이모지가 퐁퐁 샘솟으며, 끝순이 특유의 츤데레 뚱냥이 대사가 귀여운 말풍선으로 번역됩니다.
   * 턱밑을 만져주면 폭발적인 골골송과 함께 대만족 요정 단계(만족도 120%)에 달성하게 됩니다.

5. **📌 다이어리 스티커 방명록 (Guestbook)**:
   * 방문자가 닉네임, 축하 스티커(물고기, 발자국, 장난감 공, 통조림캔), 따뜻한 칭찬 메시지를 남길 수 있습니다.
   * 작성 시 진짜 다이어리 벽보에 붙인 것처럼 각각 미세하게 무작위로 기울어져 붙어 키치한 매력을 극대화합니다.
   * 작성 정보는 브라우저의 `localStorage`에 자동 저장되므로, 새로고침하거나 브라우저를 껐다 켜도 사랑스러운 메시지들이 영구히 보존됩니다.

## 📂 파일 구조

* `index.html`: 페이지 레이아웃 및 뼈대 (구조화된 시맨틱 HTML5, 접근성 고려)
* `styles.css`: 디자인 토큰, 글래스모피즘, 반응형 미디어 쿼리 및 풍부한 마이크로 애니메이션 모음
* `app.js`: 고양이 물리 체이스, 쓰다듬기 반응, 로컬 방명록, 파우 트레일 알고리즘 구현
* `images/`: 생성형 AI 기술을 활용하여 초고화질로 렌더링된 두 아이들의 사랑스러운 에셋 사진 폴더
  * `ruby_hero.png`: 멋진 은빛 코트를 뽐내는 늠름한 루비
  * `kkeutsuni_hero.png`: 뚱한 표정이 세젤귀인 몽실솜털 끝순이
  * `cats_playing.png`: 두 아이들이 다정하게 뛰노는 모습
